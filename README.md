# بازطراحی پرتال آموزشکده ملی مهارت اردکان ـ شهید بهشتی

این پروژه یک بازطراحی مستقل و واکنش‌گرا از پرتال آموزشکده است که برای انتشار به‌صورت سایت ایستا در GitHub Pages آماده شده است.

## راه‌اندازی در GitHub
1. فایل ZIP را از حالت فشرده خارج کنید.
2. تمام محتویات پوشه را در ریشه مخزن GitHub بارگذاری کنید؛ فایل `index.html` باید در ریشه باشد.
3. در مخزن به `Settings → Pages` بروید.
4. در بخش Build and deployment گزینه `Deploy from a branch`، شاخه `main` و پوشه `/ (root)` را انتخاب کنید.
5. پس از چند دقیقه آدرس GitHub Pages نمایش داده می‌شود.

## امکانات پیاده‌سازی‌شده
- رابط فارسی و راست‌چین، واکنش‌گرا برای موبایل و دسکتاپ
- سربرگ، منوی موبایل، جستجوی خبرهای نمایشی، فیلتر دسته‌بندی
- بخش اخبار، فرم‌ها، خدمات الکترونیکی، درباره مرکز، گالری، تماس و پیوندهای مرتبط
- حالت تیره، تنظیم اندازه متن، تاریخ شمسی مرورگر و دکمه بازگشت به بالا
- لینک به برخی سامانه‌های بیرونی دانشگاه و خدمات مرتبط

## نکات مهم
- این پروژه بازطراحی مستقل است، نه نسخه رسمی دانشگاه و نه کپی کامل پایگاه داده/پنل مدیریت سایت مبدأ.
- برخی متن‌های خبر و کارت‌ها نمونه‌اند؛ قبل از استفاده رسمی باید با محتوای تأییدشده جایگزین شوند.
- فرم تماس فقط نمایشی است و پیام را به سرور ارسال نمی‌کند.
- فایل‌های فرم در این نسخه به سایت مرجع پیوند دارند؛ برای نمایش فایل‌های واقعی باید فایل‌های مجاز را در پوشه‌ای مانند `assets/files/` قرار دهید و لینک‌ها را به آن‌ها تغییر دهید.
- سامانه‌های ورود دانشجویی/کارکنان در دامنه‌های مستقل دانشگاه میزبانی می‌شوند و در این سایت بازسازی یا شبیه‌سازی ورود انجام نشده است.
- GitHub Pages فقط میزبانی ایستا ارائه می‌دهد؛ برای پنل مدیریت، دیتابیس یا فرم‌های واقعی به سرویس سمت سرور نیاز است.
