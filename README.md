# بازطراحی پرتال آموزشکده ملی مهارت اردکان ـ شهید بهشتی

نسخه جمع‌وجورتر با استفاده از سه تصویر ارسال‌شده در سربرگ و ساختار نزدیک‌تر به پرتال مرجع.

## انتشار در GitHub Pages
1. فایل ZIP را استخراج کنید.
2. همه محتویات را در ریشه مخزن قرار دهید؛ `index.html` باید در ریشه باشد.
3. Settings → Pages → Deploy from a branch → شاخه `main` → پوشه `/ (root)` را انتخاب کنید.

## یادآوری
- عناوین و بخش‌ها با توجه به محتوای قابل مشاهده پرتال مرجع تنظیم شده‌اند.
- این یک بازطراحی مستقل است، نه نسخه رسمی یا کپی پایگاه داده سایت اصلی.
- برای دریافت فایل‌های اصلی و متن کامل اطلاعیه‌ها، پیوندهای سایت اصلی در نظر گرفته شده‌اند؛ متن بعضی خلاصه‌هاست.
- فرم‌ها و پنل مدیریت/ورود بازسازی نشده‌اند و فایل‌های سایت مرجع ممکن است نیاز به دسترسی یا به‌روزرسانی داشته باشند.
